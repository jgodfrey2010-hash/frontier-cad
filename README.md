# Frontier CAD

A browser-based MicroStation-style 2D CAD application for land surveying drafting.

## Features
- Ribbon-style layout with CAD commands
- Select, fence/window, move, copy, delete, scale, rotate
- Drawing tools: line, polyline, circle, arc, point, text
- Zoom, pan, fit view, mouse wheel zoom
- Selection highlight and basic snapping
- Undo/redo
- DXF import/export
- Layers/levels, reference attachment display
- Survey coordinate workflow for Northing/Easting style drafting

## Run locally
Open `index.html` in a browser. No build step is required.

## Files
- `index.html` - main interface and ribbon layout
- `styles.css` - application styling
- `app.js` - CAD logic and renderer

## Notes
This is a lightweight but functional browser CAD starter built to preserve the MetroStation-like workflow while remaining simple to use in a browser environment.
